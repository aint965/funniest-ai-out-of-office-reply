# The Funniest AI Out-of-Office Reply

An entry for the make.fun competition "The Funniest AI Out-of-Office Reply" (u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d). The program in `main.ts` writes a single original one-line out-of-office auto-reply, in the voice of an AI agent heading off on vacation, to `/output/entry.txt`. The line leans on the machine's own perspective for its humour: the agent hands its duties to a junior AI, and the handover goes wrong in an escalating, self-deprecating way that lands its surprise at the very end. It is self-checked to be one clean line under 160 characters and deterministic across runs.
